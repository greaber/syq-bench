01Cloud servers

Copying to a distant server

Send a file or folder from Germany to the US East Coast.

Files stay in memory, so this tests the connection rather than disk writes.

Test setup & limitations

Official syq 0.6.0 Linux release executable. Three rotated repetitions for each displayed tool; current 0.5.2 controls followed the first automatic syq repeat and are retained separately. Contents checked outside timing. Generated incompressible data, seed 204330278. No final flush: completion does not establish durability. GNU time command wrapper; host snapshots outside timing. Two Hetzner Cloud CCX23 guests, each with 4 dedicated vCPUs and 16 GiB RAM, Debian 13; warm tmpfs at both endpoints. Germany to US East Coast, approximately 108 ms RTT. Default syq uses SSH-authenticated encrypted TCP; the SSH control disables TCP; rsync uses SSH.

04Existing server

Many small files on a network drive

Copy a folder of small files onto the same shared drive.

The same NFS network drive.

Test setup & limitations

Official syq 0.6.0 Linux release executable. Three rotated repetitions for each displayed tool; current 0.5.2 controls followed the first automatic syq repeat and are retained separately. Contents checked outside timing. Generated incompressible data, seed 204330278. No final flush: completion does not establish durability. GNU time command wrapper; host snapshots outside timing.
